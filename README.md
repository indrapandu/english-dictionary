# My English Dictionary

A simple personal English dictionary web application designed for mobile and desktop browsers.

## Planned features

- Email and password login
- Add, edit, and delete vocabulary
- English and Indonesian meanings
- Pronunciation and part of speech
- Example sentences and translations
- Search, favorites, and mastery status

## Technology

- Frontend: HTML, CSS, and vanilla JavaScript
- Hosting: GitHub Pages
- Authentication and database: Supabase

## Current status

The responsive frontend scaffold is ready. Supabase configuration and database setup are the next step.

## Security

Only use the Supabase Project URL and publishable/anon key in `js/config.js`. Never put a Supabase `service_role` key in this repository.
